**Peformance Dashboard (A desktop application --> Python, PyQt5, Pandas, NumPy, Pyinstaller)**
A standalone desktop application built with Python & PyQt5 that automates daily logistics operations reporting — eliminating 78% of manual Excel steps across 6 reporting functions.

⚡ Works fully offline — no internet, no Python installation required on target machine.

📽️ **Demo**
https://github.com/mubzia/Performance_Dashboard/blob/main/Performance%20dashboard%20overview.mp4

✨ **Features**

📂 Upload OFD & Query data — auto-merged and processed in background thread
📊 Shein 1st & 2nd OFD performance tracking with visual bar chart
📦 Shein Batch Performance — last 4 weeks auto-calculated
💳 PPD & Reverse performance analysis
🏪 SME Clients — top 7 COD & PPD clients automatically
🚗 DPD — deliveries per driver for iMile & Afkar vendors
🗺️ Zone Analysis — SPR per zone & zones per DA
😴 Idle DA Tracking — DAs with zero deliveries
⬇️ One-click Excel downloads for every report
🔄 Clear & re-upload data without restarting the app
🖥️ Fully offline — works without internet or browser
